# Hilbert Vibration Decomposition

This function implements a variant of the Hilbert Vibration
Decomposition.

## Usage

``` r
hvd(x, n, fp)
```

## Arguments

- x:

  The input signal.

- n:

  The number of components to decompose.

- fp:

  Lowpass filter cutoff frequency.

## Value

A list containing the decomposed components, amplitudes, angular
frequencies, and relative standard deviations.
