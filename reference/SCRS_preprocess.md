# Preprocess SCRS data

Baseline and normalization for SCRS data

## Usage

``` r
SCRS_preprocess(input_dir, output, meta_fp, txt_filename)
```

## Arguments

- input_dir:

  A directory

- output:

  A directory

- meta_fp:

  A TSV file

- txt_filename:

  A prefix of file names

## Value

Results were put into output directory
