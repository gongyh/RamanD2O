# Ramanome class

This class represents a Ramanome object, which contains Raman data and
associated metadata.

## Slots

- `wavenumber`:

  Numeric vector indicating the wavenumbers

- `datasets`:

  A list of Raman datasets

- `meta.data`:

  A data frame containing metadata

- `reductions`:

  A list of data reduction results

- `interested.bands`:

  A list of interested Raman bands
