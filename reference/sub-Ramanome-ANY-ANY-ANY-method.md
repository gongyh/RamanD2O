# Subset method for Ramanome objects

Subset method for Ramanome objects

## Usage

``` r
# S4 method for class 'Ramanome,ANY,ANY,ANY'
x[i, j, ..., drop = TRUE]
```

## Arguments

- x:

  The Ramanome object

- i:

  The indices for subsetting

- j:

  Index or name of the slot to subset

- ...:

  Additional arguments

- drop:

  Boolean indicating whether to drop unused slots (default: TRUE)
